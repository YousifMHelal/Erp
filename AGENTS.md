# ERP

Arabic-only (RTL) retail shop ERP. Next.js 15 · TypeScript strict · Tailwind v4 · shadcn/ui · Prisma · PostgreSQL · Zod · NextAuth · Zustand.

**All project context lives in [`context/`](./context/). Read it before writing any code.**

Start with **[context/AGENTS.md](./context/AGENTS.md)** — it holds the operating rules and the read order for the other five documents:

| Doc | What it holds |
|-----|---------------|
| [context/AGENTS.md](./context/AGENTS.md) | Operating rules, workflow, definition of done |
| [context/ARCHITECTURE.md](./context/ARCHITECTURE.md) | Scope, tech stack, folders, data model, non-negotiables |
| [context/MEMORY.md](./context/MEMORY.md) | Locked decisions with rationale, open questions |
| [context/BUILD_PLAN.md](./context/BUILD_PLAN.md) | Phased tasks with IDs |
| [context/UI_DESIGN_RULES.md](./context/UI_DESIGN_RULES.md) | Binding design tokens and visual rules |
| [context/PROGRESS_TRACKER.md](./context/PROGRESS_TRACKER.md) | What's done — update after every task |
